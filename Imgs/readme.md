# 🖼️ Imatges

Captures i fotos de les pràctiques. El nom segueix el format `pX-NN-descripcio.jpg`,
on `pX` és la pràctica i `NN` el pas on s'utilitza a la [bitàcora setmanal](../Bitacora/Setmanal.md).
